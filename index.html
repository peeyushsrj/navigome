How to use Navigome

  • States: morning (spiritual) · daytime (work + errands) · sunset (nature) · evening (errands) · night (self-care). The clock picks the active state from its time window.
  • Override: tap any state chip to hold it manually until that state's window ends — then the clock takes over again automatically.
  • Tasks: shown from your Vikunja project(s) mapped to the state. Tick a checkbox to mark it done in Vikunja.
  • First run: paste your Vikunja API token (Vikunja → Settings → API token) in Settings, then Test connection.
  • Adjust windows / project mapping: edit config.js — start/end times and project IDs per state.
  • Refresh: re-resolves every 30s; pull-to-refresh or reload anytime.
